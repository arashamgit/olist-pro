# بسته تحویل پروژه

<div dir="rtl" align="right">

## ۱. فایل بسته

`deliverables/olist-pro-deliverables.zip`

ساخت مجدد بسته با یک دستور:

```bash
python scripts/build_deliverables.py
```

خروجی دستور، تعداد فایل‌ها و اندازه واقعی بسته را چاپ می‌کند و در پایان سیاست
محتوا را بررسی می‌کند (هیچ داده خام، محیط مجازی یا کشی در بسته نباشد).

نمونه آخرین ساخت اندازه‌گیری‌شده: **۱۹۲ فایل**، **۱۹۳ ورودی**، حدود
**۵.۹ مگابایت** و خروجی `policy : OK - no raw CSV, no virtualenv, no cache`.

## ۲. محتوای بسته

| مسیر | توضیح |
| :--- | :--- |
| `README.md` | معرفی پروژه و راهنمای شروع |
| `requirements.txt`, `pyproject.toml` | وابستگی‌ها و تنظیمات ابزارها |
| `src/olist_analysis/` | کد ماژولار تحلیل (پیکربندی، بارگذاری، کیفیت، پاک‌سازی، ویژگی‌ها، متریک‌ها، نمودارها، گزارش، فونت) |
| `scripts/` | دروازه کیفیت داده، اجرای خط لوله، ساخت و اجرای نوتبوک‌ها، ساخت گزارش، ساخت بسته، اجرای آزمون‌ها |
| `tests/` | مجموعه آزمون‌ها روی داده واقعی و داده ساختگی |
| `notebooks/` | ۱۳ نوتبوک، هر یک با خروجی اجراشده |
| `docs/` | صورت‌مسئله، منشور، واژه‌نامه داده، روابط، تصمیم‌های پاک‌سازی، روش‌شناسی، نگاشت الزامات، گردش کار تیمی، نقشه راه، دفتر تحلیل |
| `docs/implementation_guide/` | راهنمای بازسازی گام‌به‌گام + راهنمای نمونه‌های عملی |
| `docs/validation/` | گزارش ممیزی نهایی با وضعیت هر بررسی |
| `reports/figures/` | ۳۱ نمودار PNG با فونت فارسی و جهت راست‌به‌چپ |
| `reports/tables/` | ۵۸ جدول تحلیل با اعداد دقیق هر تحلیل + `figure_manifest.csv` فهرست نمودارها |
| `reports/metrics.json` | همه شاخص‌های کسب‌وکار در یک فایل |
| `reports/executive_report.md` و `.pdf` | گزارش مدیریتی فارسی (حدود ۴۶۶ کیلوبایت) |
| `MANIFEST.txt` | فهرست کامل فایل‌های بسته با تاریخ ساخت (UTC) |

## ۳. موارد خارج‌شده از بسته

| مورد | علت |
| :--- | :--- |
| `data/raw/*.csv` (۱۲۰.۲۵ مگابایت) | حجم بالا؛ روش تهیه در `data/README.md` |
| `data/interim`, `data/processed` | کاملاً قابل بازتولید با یک دستور |
| `.venv`, `__pycache__`, `.ipynb_checkpoints`, `.pytest_cache` | محیط موقت |
| `artifacts/` | خروجی‌های موقت اجرای تحلیل |
| هر فایل کلید، رمز یا اطلاعات حساس | پروژه هیچ کلید خارجی یا اطلاعات مشتری واقعی ندارد |

برای اعداد دقیق اندازه بسته، خروجی `build_deliverables.py` را ببینید؛ اندازه در
مستندات به‌صورت عدد ثابت ثبت نشده تا با هر اجرا کهنه نشود.

## ۴. نحوه بازبینی بسته

۱. بسته را در یک پوشه خالی باز کنید.
۲. `docs/validation/final_validation_report.md` را بخوانید تا وضعیت هر بررسی و
   موارد باقی‌مانده را ببینید.
۳. `reports/executive_report.pdf` را باز کنید؛ این فایل مستقل از کد و نوتبوک قابل
   خواندن است.
۴. برای بازسازی کامل محیط، `docs/implementation_guide/00_environment_setup.md` و
   سپس `data/README.md` را دنبال کنید.
۵. برای اعتبارسنجی اعداد، `python scripts/validate_data.py` و بعد
   `python -m pytest -q` را اجرا کنید.
