## ۶. محتوای مورد انتظار

### توابع بخش ۱۲ (فروشندگان)

| تابع | خروجی | نکته طراحی |
| :--- | :--- | :--- |
| `seller_overview` | تعداد، میانه اقلام و مبلغ، سهم ده فروشنده اول | مخرج صریح |
| `sellers_by_state` | تعداد فروشنده هر ایالت | - |
| `seller_performance` | یک ردیف برای هر فروشنده | حجم، مبلغ، امتیاز، تعداد نظر، هر دو رتبه |
| `top_sellers` | ده فروشنده برتر | بر اساس مبلغ یا حجم |
| `high_revenue_low_rating_sellers` | فروش بالا با امتیاز پایین | آستانه نسبی: صدک ۹۰ مبلغ و ۰.۵ کمتر از میانگین |

**نکته مهم:** امتیاز فروشنده باید از گرین «سفارش-فروشنده» محاسبه شود. اگر از
ردیف‌های اقلام حساب کنید، سفارشی که چند قلم از یک فروشنده دارد امتیازش چند بار
شمرده می‌شود. همچنین فقط ۶۲۸ فروشنده (۲۰.۲۹٪) حداقل ۳۰ نظر دارند؛ برای بقیه،
امتیاز قابل اتکا نیست.

### شش تابع ترکیبی

| تابع | ترکیب | نکته طراحی |
| :--- | :--- | :--- |
| `combined_revenue_vs_satisfaction` | دسته‌بندی × امتیاز × مبلغ | پرچم‌گذاری بر پایه چارک مبلغ و مقایسه با میانگین |
| `combined_geography_delivery` | ایالت × زمان تحویل × نرخ تأخیر | تعریف «نیازمند توجه» بر پایه **میانه** هر دو شاخص |
| `combined_price_vs_satisfaction` | قیمت قلم × امتیاز سفارش | دهک قیمت + ضریب اسپیرمن + هشدار علیت |
| `combined_payment_vs_installments` | مبلغ × اقساط | هم سطح تراکنش، هم سطح سفارش |
| `combined_category_revenue_over_time` | دسته × ماه × مبلغ | تفکیک رشد پایدار از جهش تک‌ماهه با ضریب تغییرات |
| تحلیل ششم (فروشنده × رضایت) | از `high_revenue_low_rating_sellers` | معرفی حداقل سه فروشنده با ذکر تعداد نظر |

### تله‌هایی که باید دور بزنید

۱. **آستانه دستی.** «پرفروش» یا «امتیاز پایین» را با عدد ثابت دلبخواه تعریف
   نکنید؛ از چارک، صدک و فاصله از میانگین استفاده کنید و آن را مستند کنید.
۲. **تفکیک رشد پایدار از جهش.** اگر فقط ابتدا و انتهای بازه را مقایسه کنید، یک
   جهش تک‌ماهه به‌اشتباه «رشد پایدار» خوانده می‌شود. ضریب تغییرات را هم گزارش
   کنید.
۳. **مقایسه دسته‌بندی‌های بی‌ربط.** در نوتبوک ۱۱ توضیح دهید که آستانه‌ها نسبی و
   وابسته به همین داده‌اند و با داده به‌روز، فهرست پرچم‌خورده‌ها تغییر می‌کند.
