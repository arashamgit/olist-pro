### آزمایش کنترل‌شده رندر فارسی

شک اولیه این بود که متن فارسی نمودارها نادرست رندر می‌شود. یک آزمایش شش‌حالته که
همه روش‌ها را در یک تصویر کنار هم می‌کشد ساخته و نتیجه مشاهده شد
(Matplotlib 3.11.1 با Raqm، فونت Vazirmatn):

| حالت | نتیجه مشاهده‌شده |
| :--- | :--- |
| متن خام فارسی | درست: حروف متصل و ترتیب راست‌به‌چپ |
| فقط `arabic_reshaper` | درست (فقط شکل حروف عوض می‌شود) |
| `reshape + get_display` (تابع `fa`) | **ترتیب کلمات برعکس** |
| `fa` دو بار | دوباره درست (برگشت به همان متن خام) |
| متن مخلوط فارسی و لاتین، خام | درست؛ عدد و پرانتز سر جای خود |
| همان متن مخلوط با `fa` | برعکس |

**نتیجه:** نسخه‌های جدید Matplotlib خودشان شکل‌دهی حروف و الگوریتم Bidi را
انجام می‌دهند، پس متن نمودارها باید خام بماند و `fa` فقط برای PDF (ReportLab که
چنین موتوری ندارد) به کار برود. بر این پایه `font_utils.t` متن خام را برمی‌گرداند
و `font_utils.fa` مخصوص گزارش PDF است؛ عنوان‌ها هم در `plotting._save`
راست‌چین و از تکرار پاک می‌شوند.
